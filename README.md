# VadymDev — Personal Portfolio Website

A clean, modern, and minimalistic personal portfolio website showcasing my work, skills, and services as a Web Designer and Frontend Developer. The project focuses on elegant UI, smooth animations, and a fully responsive experience across all devices.

## 🚀 About the Project

This website serves as a professional presentation of my abilities, helping potential clients and employers quickly understand:
- my design taste,
- development approach,
- attention to detail,
- and ability to deliver high-quality, user-friendly interfaces.

The main goal of the project is to make the first impression strong, clear, and visually appealing.

## 🛠️ Technologies Used
- **HTML**
- **CSS**
- **JavaScript**

## ✨ Features
- Fully responsive layout  
- Smooth transitions and subtle animations  
- Clean and minimalistic UI  
- Service sections (Web Design, Frontend Development, UI Improvements)  
- Testimonials section  
- Contact form with a dedicated “Thank You” page  
- Lightweight performance-focused structure
